## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine → GitHub remote | Content crosses from a private laptop to a hosted service whose visibility setting determines whether the whole internet can read it. This is the only boundary Phase 1 crosses that has an irreversible failure mode. |
| owner's browser → GitHub account | An interactive sign-in; the identity that authenticates determines which account owns the pushed history. |
