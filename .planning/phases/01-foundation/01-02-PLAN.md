shell on this machine is Windows PowerShell 5.1**, which is not POSIX: `&&` is a parse error and

`spawnSync` with an argv array (and `npm.cmd` on win32), unknown check id exits non-zero, a check

`01-01-PLAN.md`'s `<shell_contract>`. Follow them; do not fork a second verification mechanism.
